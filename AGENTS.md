# Development workflow

- Always use the `pronto:pronto-turn` skill for development in this repository.
- Preserve Pronto's declared program and generated-file ownership. Use the
  applicable Sayt gates to verify changes.
- Use the Stitch MCP to help explore and refine layout changes. Carry accepted
  design decisions into `apps/golaberto/ir.html` and implement them through
  Pronto. If Stitch is unavailable, report the connection issue.
