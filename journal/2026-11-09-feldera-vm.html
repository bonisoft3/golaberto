Teams remain available while native streaming state rebuilds

9 November 2026. The private GCP VM serves the imported archive from native PostgreSQL while precompiled Feldera pipelines consume CDC. The runtime image contains the pipeline executables; compilation stays in the build.

Deployment checks
The final bounded-batch image passed the HTTP sweep: 294 immutable assets, six catalogues, 17 document routes, and the negative cache-poisoning probe. Golaberto build and tests passed. The appliance integration passed all 12 steps, including PostgreSQL durability, Electric recovery, and Caddy data-directory configuration.
Memory finding
The CDC library's emergency guard counts the full container memory charge, including file cache. A smaller container limit stalled ingestion despite empty input queues. Reclaiming that cache resumed ingestion immediately. The dedicated 4 GiB VM trial now uses host-memory accounting, with the guard still enabled, 1 MiB connector batches, and bounded input queues.
